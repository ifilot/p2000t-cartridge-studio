P2000T PROGRAMMABLE CARTRIDGE PREPARATION TOOL
==============================================

Run p2000t-programmable-cartridge-preparation-tool.exe and follow the menu.
Keep all files in this folder together. No separate AVRDUDE installation is
required.
The product release is recorded in version.txt and is shared by the desktop app,
firmware, protocol and this preparation utility.
The preparation tool itself is licensed under GNU GPL version 3; see license.txt.

Keep the cartridge out of the P2000T. Do not connect the cartridge USB port
while the USBasp powers the ISP contacts. Hold the ISP contacts steady until
the program says they may be released.

The included avrdude.exe and avrdude.conf are unmodified files from AVRDUDE 8.2:
https://github.com/avrdudes/avrdude/releases/tag/v8.2

AVRDUDE is a separate program distributed under GNU GPL version 2. Its licence
is in avrdude-copying.txt, and its complete corresponding source is included as
avrdude-v8.2-source.tar.gz.
