# AVRDUDE

P2000T Cartridge Studio bundles the official 64-bit Windows build of AVRDUDE
8.2 to install application firmware through the cartridge's AVR109 USB
bootloader.

- Project: https://github.com/avrdudes/avrdude
- Release: https://github.com/avrdudes/avrdude/releases/tag/v8.2
- Archive: `avrdude-v8.2-windows-x64.zip`
- Archive SHA-256: `e2a89a921e1b2fe675a319248ea968c7e28c7edc44c5fd836e2879a3e094c9cf`
